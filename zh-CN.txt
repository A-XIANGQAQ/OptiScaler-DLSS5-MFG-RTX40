; ============================================================================
;  OptiScaler 简体中文语言文件
;
;  放置位置（任选其一，优先上面的）：
;    <游戏目录>\zh-CN.txt                      -- 与 OptiScaler.ini 同级
;    <游戏目录>\OptiScaler\language\zh-CN.txt
;    <游戏目录>\OptiScaler\zh-CN.txt
;
;  格式：  English=译文
;    - 以 ; 或 # 开头的行是注释，整行忽略
;    - 分隔符是「第一个未被转义的 =」，等号后面的内容全部属于译文。
;      键里本身含等号时（如 "1080 / 1.5 = 720"）写成 \= ，
;      否则会被从中间切断、永远匹配不上
;    - 两侧空白会被去掉
;    - 支持 \n \r \t \s \= \\ 转义，所以多行文本也能写在一行里
;    - 少数条目的首尾空格是有意义的（如 " 在 Vulkan 上原生运行"），
;      用 \s 表示一个空格，它不会被当作空白裁掉
;    - 键名里的 "##xxx" 是 ImGui 的内部 ID，写不写都一样，
;      本文件按显示文本填写即可
;    - 带 % 的条目是 printf 格式串，译文里的 %s %d %.2f 等必须原样保留
;
;  改完保存即生效，不需要重新编译。删掉本文件就回到英文界面。
